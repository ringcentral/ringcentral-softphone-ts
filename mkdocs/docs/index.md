# RingCentral Softphone SDK for TypeScript

Build headless RingCentral calling integrations in Node.js. The SDK supports
inbound and outbound calls, audio streaming, DTMF, transfer, hold, and unhold
without a browser or graphical interface.

[Get started](getting-started.md){ .md-button }

## What you can build

- Answer, decline, place, cancel, transfer, and hang up calls.
- Receive decoded audio and stream audio to a remote participant.
- Send and receive DTMF.
- Run multiple headless softphones from a Node.js service.

## Documentation policy

The repository [README](https://github.com/ringcentral/ringcentral-softphone-ts#readme)
is the source of truth. This site organizes the same supported behavior into
task-focused guides.

This project replaces the retired
[RingCentral Softphone SDK for JavaScript](https://github.com/ringcentral/ringcentral-softphone-js)
and is recommended for new integrations.
